# 期货实时分析助手

本地 Web 应用：国内期货**准实时行情看板** + **AI 分析对话**。

- 数据源：[AkShare](https://github.com/akfamily/akshare)（新浪财经转发），免费、约 3~5 秒延迟，覆盖上期所 / 大商所 / 郑商所 / 中金所 / 上期能源 / 广期所的主力连续合约
- AI 对话：支持**智谱 GLM**（`open.bigmodel.cn`）与 **DeepSeek**（`platform.deepseek.com`），OpenAI 兼容接口，Key 只保存在本机

> ⚠️ 本应用仅供研究学习，所有数据与 AI 输出均不构成投资建议；不具备下单功能，请通过期货公司正规渠道交易。

## 快速开始

```bash
# 1. 安装依赖（仅首次）
pip install -r requirements.txt

# 2. 启动
python app.py            # 或直接双击 start.bat

# 3. 浏览器打开
# http://127.0.0.1:8300
```

启动时会自动预热数据接口（约 3~10 秒），完成后页面每 5 秒自动刷新行情。

## 配置 AI 对话

1. 页面右上角 **「⚙ AI 设置」**
2. 选择服务商（智谱 GLM / DeepSeek），填入对应开放平台申请的 API Key
   - 智谱：<https://open.bigmodel.cn>（`glm-4-flash` 模型目前免费）
   - DeepSeek：<https://platform.deepseek.com>（`deepseek-chat`）
3. 保存后即可在对话窗口提问，或点 **「📊 分析当前合约」** 一键分析选中的合约

AI 会自动获得当前自选合约的实时行情与选中合约近 10 个交易日日线作为上下文。Key 保存在本项目根目录 `config.json`（已加入 `.gitignore`，不会提交），可用弹窗中的「清除已存 Key」移除。

## 功能说明

| 功能 | 说明 |
| --- | --- |
| 自选行情看板 | 添加/删除主力合约，5 秒自动刷新，红涨绿跌；点击表头排序；价格变动闪烁；**支持拼音首字母搜索**（输入 `lw` 即出螺纹钢，代码/名称/拼音均可，键盘上下+回车选择） |
| 合约详情 | 最新价、开高低、昨结算、**买一/卖一盘口**、成交量、持仓量；**实时走势图**（5 秒采样）；**日内分时图**（价格+均价+昨结基准） |
| **K 线蜡烛图** | 红涨绿跌蜡烛 + MA5/10/20 均线 + 成交量副图（红绿柱）+ 最新价虚线价签 + **技术信号标记**（▲看多 ▼看空 ◆警示）+ 十字光标浮窗（OHLC/量仓/MA）；周期切换：1/5/15/30/60 分钟与日线 |
| **技术信号** | 后端计算 MA、MACD、RSI、KDJ、BOLL，自动检测金叉死叉、超买超卖、均线多空排列、布林突破 |
| **价格预警** | 上破/下破价格阈值，触发时横幅 + 三连声音提醒 + **标签页标题闪烁**（切到别的页面也能看到），触发后自动撤销 |
| **AI 盯盘** | 后台每 30 秒巡检自选 + 重点品种（默认原油 SC0、黄金 AU0），基于 1 分钟线检测**5 分钟急涨急跌**；阈值按品种适配（股指 0.2% / 贵金属 0.3% / 商品 0.5%），同方向 15 分钟冷却防轰炸；触发后**自动推送**（面板事件流 + 横幅 + 双低音提醒 + 标签页标题闪烁）并**自动生成 AI 一句话解读**（驱动因素/关注价位）；可在 AI 设置中开关与调节灵敏度 |
| **主题要闻** | 左栏「📰 要闻」页签：新浪全球快讯（市场异动流）+ 东方财富全球快讯双源聚合，**原油/黄金/贵金属 + 美联储/地缘等宏观驱动关键词自动过滤与高亮**；命中主题的条目橙色标记，每 40 秒刷新，新命中要闻横幅提醒；东财条目可点击跳转原文 |
| **对比分析**（中栏 Tab） | 两品种**比价/价差/归一化对比**（60/120/250 日），比价图带均值与 ±1σ/±2σ 统计通道，**历史分位警示**（≥80% 或 ≤20% 标记"极端"）；一键交给 AI 做套利视角分析；下方**品种相关性矩阵**（自选品种日收益率热力图，红正绿负） |
| **AI 晨报** | 顶栏「📋 晨报」：自动汇总主题要闻 + 自选品种行情与技术信号，生成市场概览/分品种要点/今日关注三段式简报（Markdown）；晨报（9-21 点）与夜报（21 点后）分时段缓存，落盘保留最近 6 份，可手动重新生成 |
| AI 分析对话 | 结合**实时行情 + 技术指标 + 信号**上下文；Markdown 排版；等待计时与超时提示；链路自检：访问 `/?selftest=1` |
| 交易时段提示 | 顶栏显示交易时段状态（简化判断） |

## 已知限制

- 免费数据为**准实时**（数秒延迟），不适合高频/程序化交易；需要 tick 级数据请考虑期货公司 CTP 接口
- 非交易时段显示的是最近收盘快照
- 新浪接口为非官方渠道，AkShare 升级可能偶尔改变字段（`pip install -U akshare` 通常可解决）
- 涨跌以**昨结算价**为基准（期货惯例）；中金所品种结算价缺失时以昨收盘价近似

## 常见问题

- **启动慢 / 首次行情加载慢**：正常，预热 + 首轮拉取需要数秒
- **某合约显示"行情获取失败"**：多为新浪侧偶发失败，下一轮刷新会重试
- **AI 报 401**：API Key 无效；报 429：请求过频或额度不足
- **推理型模型（如 deepseek-v4-pro）回复慢/空**：此类模型会先生成思维链再输出正文，短任务也可能耗时 30 秒以上；盯盘解读已按此适配（token 给足），若仍偏慢可在设置中换轻量模型
- **验证盯盘链路**：非交易时段想测试提醒效果，可 `curl -X POST http://127.0.0.1:8300/api/monitor/test` 注入一条模拟异动
