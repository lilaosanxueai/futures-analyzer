# 期货心理博弈分析助手

本地 Web 应用：以**四方资金心理博弈**（产业 / 主力 / 投机 / 散户）为底层逻辑的期货分析与交易诊断工具。

> 2026-09 彻底重构：去掉全部技术指标、资讯流、宏观日历功能，全面转向
> **散户心理分析 + 资金博弈推断 + 个人交易记录实时诊断**。

## 核心逻辑

价格不是图形，是四方资金的博弈结果。本应用只用最原始的价、量、持仓三要素推断：

- 🏭 **产业（套保盘）**：高位卖保压制、低位买保支撑（按价格周期分位推断）
- 🏦 **主力（机构资金）**：持仓量 × 价格的八状态组合（增仓上行=新多进攻 / 增仓下行=空头施压 / 减仓上行=空头回补 / 减仓下行=多头撤退…）——最硬的证据
- ⚡ **投机（短线热钱）**：日内量能比 + 短时动能
- 🐑 **散户（群体心理）**：按 9 种行情阶段剧本推断"在想什么、会怎么操作、陷阱指数多高"

分析的落点永远是：**拆穿散户幻想，顺应大势、顺应资金方向、顺应品种现状、顺应情绪。**

## 功能

| 模块 | 内容 |
|---|---|
| 工作台 | 自选博弈看板（持仓变化 / 资金方向 / 散户陷阱指数）、外盘大势锚、预警事件流、AI 反幻想教练对话 |
| 品种博弈 | 行情阶段剧本、四方博弈卡片（散户卡片含心理活动与可能操作）、危险行为警告、顺应结论、资金证据明细、AI 深度解读 |
| 交易诊断 | 记一笔开仓即检（逆资金方向 / 追涨杀跌 / 抄底左侧 / 重仓 / 超频 / 报复交易当场暴露）、持仓 60 秒盯防（扛单越损=致命预警+飞书推送）、行为统计（散户病计数） |
| 交易心得 | 心得 + 飞书同步 + AI 行为模式复盘 |
| 晨/夜报 | 自动生成心理博弈简报推飞书（含"今日不做清单"） |

## 快速开始

```bash
# 1. 安装依赖（仅首次）
pip install -r requirements.txt

# 2. 启动
python app.py            # 或直接双击 start.bat

# 3. 浏览器打开
# http://127.0.0.1:8300
```

- 数据源：[AkShare](https://github.com/akfamily/akshare) + 新浪行情直连（约 3~5 秒延迟），覆盖国内各交易所主力连续合约
- 日线使用**主连连续合约**（持仓为全市场口径），避免换月滚仓污染资金推断
- AI：智谱 GLM / DeepSeek / 自定义 OpenAI 兼容端点，多服务商自动降级，Key 只保存在本机 `config.json`

## 配置 AI

1. 页面右上角 **「⚙ 设置」**
2. 选择服务商，填 API Key（智谱 <https://open.bigmodel.cn> / DeepSeek <https://platform.deepseek.com>）
3. 同一弹窗可配风控参数（账户权益 / 单笔风险% / 日止损线 / 日开仓上限 / 冷静期）与飞书推送（App 凭证 + 群机器人 Webhook）

## 服务守护

`guardian.bat` + `guardian_hidden.vbs` 提供无人值守：崩溃自动重启、开机自启、日志轮转。
（`shell:startup` 放 `guardian_hidden.vbs` 快捷方式即可）

> ⚠️ 本应用仅供研究学习，所有数据与 AI 输出均不构成投资建议；不具备下单功能，请通过期货公司正规渠道交易。
