# 期货实时分析助手

本地 Web 应用：国内期货**准实时行情看板** + **AI 分析对话**。

- 数据源：[AkShare](https://github.com/akfamily/akshare)（新浪财经转发），免费、约 3~5 秒延迟，覆盖上期所 / 大商所 / 郑商所 / 中金所 / 上期能源 / 广期所的主力连续合约
- AI 对话：支持**智谱 GLM**（`open.bigmodel.cn`）与 **DeepSeek**（`platform.deepseek.com`），OpenAI 兼容接口，Key 只保存在本机

> ⚠️ 本应用仅供研究学习，所有数据与 AI 输出均不构成投资建议；不具备下单功能，请通过期货公司正规渠道交易。

## 服务守护（推荐配置一次）

`guardian.bat` + `guardian_hidden.vbs` 提供无人值守能力：服务崩溃 5 秒自动重启、开机登录自启、端口被占用时让位复查、日志超 10MB 自动轮转。

安装（无需管理员权限）：

1. Win+R 输入 `shell:startup` 回车，打开启动文件夹
2. 把 `guardian_hidden.vbs` 的**快捷方式**放进去（或直接复制该文件）

之后每次登录 Windows 守护自动运行；服务异常退出 5 秒内自动拉起。手动启停仍可用 `start.bat`（停止：任务管理器结束 python 进程即可，守护会在 5 分钟内让位检查后发现端口已释放）。

## 快速开始

```bash
# 1. 安装依赖（仅首次）
pip install -r requirements.txt

# 2. 启动
python app.py            # 或直接双击 start.bat

# 3. 浏览器打开
# http://127.0.0.1:8300
```

启动时会自动预热数据接口（约 3~10 秒），完成后页面每 5 秒自动刷新行情。

## 配置 AI 对话

1. 页面右上角 **「⚙ AI 设置」**
2. 选择服务商（智谱 GLM / DeepSeek），填入对应开放平台申请的 API Key
   - 智谱：<https://open.bigmodel.cn>（`glm-4-flash` 模型目前免费）
   - DeepSeek：<https://platform.deepseek.com>（`deepseek-chat`；视觉模型 `deepseek-v4-flash-vision-exp` 支持图片输入）
3. 保存后即可在对话窗口提问，或点 **「📊 分析当前合约」** 一键分析选中的合约

AI 会自动获得当前自选合约的实时行情与选中合约近 10 个交易日日线作为上下文。Key 保存在本项目根目录 `config.json`（已加入 `.gitignore`，不会提交），可用弹窗中的「清除已存 Key」移除。

### 图片对话（视觉模型）

对话支持附图：**Ctrl+V 粘贴截图**（页面任意位置）、**📎 按钮选择**、**拖拽**到输入框，单条最多 4 张，自动压缩（最大边 1568px JPEG）。发送后 AI 结合图片与行情上下文分析（如识别行情软件截图中的 K 线形态）。需在「⚙ AI 设置」中选用视觉模型：DeepSeek `deepseek-v4-flash-vision-exp` 或智谱 `glm-4v-flash`。

2. 在「权限管理」中开通：**云文档 → 文档（查看、编辑、创建）** 相关权限

## 已知限制

- 免费数据为**准实时**（数秒延迟），不适合高频/程序化交易；需要 tick 级数据请考虑期货公司 CTP 接口
- 非交易时段显示的是最近收盘快照
- 新浪接口为非官方渠道，AkShare 升级可能偶尔改变字段（`pip install -U akshare` 通常可解决）
- 涨跌以**昨结算价**为基准（期货惯例）；中金所品种结算价缺失时以昨收盘价近似

## 常见问题

- **启动慢 / 首次行情加载慢**：正常，预热 + 首轮拉取需要数秒
- **某合约显示"行情获取失败"**：多为新浪侧偶发失败，下一轮刷新会重试
- **AI 报 401**：API Key 无效；报 429：请求过频或额度不足
- **推理型模型（如 deepseek-v4-pro）回复慢/空**：此类模型会先生成思维链再输出正文，短任务也可能耗时 30 秒以上；盯盘解读已按此适配（token 给足），若仍偏慢可在设置中换轻量模型
- **验证盯盘链路**：非交易时段想测试提醒效果，可 `curl -X POST http://127.0.0.1:8300/api/monitor/test` 注入一条模拟异动
